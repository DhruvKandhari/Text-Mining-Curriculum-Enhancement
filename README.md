# 📝 Text Mining for Educational Improvement – NLP in Action

### 👋 About This Project
In this exciting text mining project, I analyzed extensive feedback from university co-op programs (2014-2020) to identify skill gaps and propose improvements for educational curriculum and student development.

### 🎯 What I Aimed to Achieve
- Highlight key skill gaps identified by employers and students through sentiment and frequency analysis.
- Provide actionable curriculum recommendations to enhance student preparedness.

### 🛠️ How I Did It (Skills & Tools Used)
- **Natural Language Processing (NLP)** *(Python, NLTK, Text Mining techniques)*
- **Sentiment Analysis & Text Classification** *(Azure ML, Python, R)*
- **Data Visualization & Insights Communication** *(Excel, Tableau, Word Cloud Visualization)*
- **Curriculum Development & Recommendations**

### 📈 What I Found
- Major gaps in Advanced Excel, Communication, Technical Skills, and Public Speaking.
- Employer feedback revealed mixed sentiments, pinpointing clear areas for improvement.

### 🌟 Recommendations Delivered
- Implement targeted skill-development programs in Advanced Excel and Communication.
- Focus on public speaking, technical proficiency, and project management in curriculum updates.

### 🙋‍♂️ My Role in This Project
- Conducted NLP analyses and sentiment classification to reveal critical insights.
- Developed visualizations to effectively communicate findings and insights.
- Led the final presentation, clearly outlining recommended educational enhancements.
